The biggest hurdle that traditional blockchains and Web2 platforms lack the ability to overcome is sybil-resistance. In order to truly be able to _coordinate_ a population, we have to know that that population is real. Without sybil-resistance, nothing is real. Everything turns into a manipulatable theater, where identities mean very little and consensus on issues can be forged.

Society Protocol solves the issue of sybil-resistance in a very elegant way: by incorporating time and using it to re-distribute socioeconomic value in the state machine model. The game theory inside of Society Protocol mimics the energetic concepts of the universe: _nothing is free, everything costs Energy._ That’s how we distinguish that something is real in the real world (costly signals), and that’s exactly the same way Society Protocol distinguishes real Actors from those which are sybil identities in its 4D state machine model of the universe filled with “Energy” — _costly signals_.

It’s important that each Value Function maintains a non-forgeable cost, abiding by the karmic concept of: _nothing is free, everything must be paid for in Energy (time)._ In practice, this is achieved by using the Activity Scores combined with the [Hunting](https://societyprotocol.io/Published/Handbook/Function-Hunting/) and [Parenting](https://societyprotocol.io/Published/Handbook/Function-Parenting/) Value Functions[^19] in our original design.

In order to truly coordinate a populace optimally, no function in the system should be exploitable, neither by singular Individual Actors nor a cabal/cartel of Actors exerting undue influence due to their close relationships.

We believe that the original Value Functions (VFs) in Society Protocol are capable of accomplishing these requirements. Most VFs pin Individual Actor's interests against each other—making aggregating as small groups unnecessary/unexploitable. The only VF in which a small organized group can exert undue influence (appears to us) to be the [Distributed Courts (dCourts)](https://societyprotocol.io/Published/Handbook/Function-Governance+(Distributed+Courts)/) Value Function[^20].

We believe our system has achieved this.
